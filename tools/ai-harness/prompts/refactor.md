## Rules

- Preserve existing behavior.
- Do not add new features unless required.
- Do not create scene objects.
- Do not modify scenes or prefabs.
- Improve S.O.L.I.D. compliance.
- Remove duplicated logic.
- Improve readability.
- Improve performance where reasonable.
- Keep inspector compatibility.
- Do not rename serialized fields unless necessary.
- Use Odin Inspector for organization.
- Add comments to all methods.
- Check for obsolete APIs.
- Remove all new warnings before finishing.

## Before Editing

First provide:
1. Current problem.
2. Proposed structure.
3. Files to change.
4. Compatibility risks.

## Done When

- Behavior is preserved.
- Code is cleaner and more modular.
- Repetition is reduced.
- No new warnings remain.
- Validation was run when possible.
- Changed files are listed.
- Manual Unity setup changes are explained.
